Change `theme.seedColor` in `m3blog.config.json` and the entire blog recolors: surfaces, containers, buttons, chips, code highlighting and the favicon.

<!-- more -->

## How

m3blog uses [Material Color Utilities](https://github.com/material-foundation/material-color-utilities), the same HCT color engine behind Android's dynamic color. From one seed it builds tonal palettes and maps them to roles like `primary`, `on-primary-container` and `surface-container-high`. Both light and dark schemes are generated, and the right one is picked from the visitor's system setting or the theme toggle.

## Scheme variants

The `theme.variant` option controls how the seed is interpreted:

| Variant | Character |
| --- | --- |
| `tonalSpot` | The default Material look: calm, balanced. |
| `vibrant` | Pushes chroma for bolder containers. |
| `expressive` | Shifts hues away from the seed for surprising, playful pairings. |
| `content` / `fidelity` | Stay close to the exact seed color. |
| `neutral` / `monochrome` | Quiet, nearly grey schemes. |
| `rainbow` / `fruitSalad` | Colorful, multi-hue schemes. |

Increase `theme.contrast` (up to `1`) for a higher-contrast scheme.
